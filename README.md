# LLM and AI Agent Experiments

This repository contains three practical experiments implemented using Python and Google Colab. These experiments demonstrate the use of Large Language Models (LLMs), AI agents, tool integration, and task automation.

## Experiments

### Experiment 7 — Building a Simple Conversational Chatbot using an LLM API
**Objective:** To build a conversational chatbot that uses a Large Language Model API to understand user queries and generate responses.

**Notebook:** `Experiment-7-LLM-Chatbot.ipynb`

### Experiment 8 — Building an LLM Agent with Tool Use
**Objective:** To build an LLM-based agent that can use external tools to perform tasks and generate useful results.

**Notebook:** `Experiment-8-LLM-Agent-Tool-Use.ipynb`

### Experiment 9 — Building a Task-Automation Agent (Web Search + Summarize Workflow)
**Objective:** To develop an AI agent that searches for information on the web and summarizes the collected information automatically.

**Notebook:** `Experiment-9-Task-Automation-Agent.ipynb`

## Technologies Used

- Python
- Google Colab
- Large Language Models (LLMs)
- LLM APIs
- AI Agents and Tool Use
- Web Search and Text Summarization

## How to Run the Experiments

1. Open the required `.ipynb` notebook in this repository.
2. Download the notebook or open it in Google Colab.
3. Configure the required API keys and dependencies.
4. Run the notebook cells in order.
5. Observe the output and results.
